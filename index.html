操作步骤
  1. 在电脑上取票据：curl -s 'https://your-target.example/mweb-json/getSignature.do?url=<本页完整URL>'，把 corpid 和 jsapi_ticket 填到上面（票据轮换很快，取完立即测）。
  2. 本页 URL 与第 1 步 url 参数必须完全一致（https、大小写、末尾斜杠、query 全部一致，不要带 #）。
  3. 把本页部署到 HTTPS 地址（如 Cloudflare Tunnel / 自建 VPS / 目标可信域名下的测试文件）。
  4. 在企微聊天里把链接发给自己/测试同事，在聊天中点击打开（不是用系统浏览器或微信打开）。
    链接后加 ?corpid=xxx&ticket=xxx 自动填参；加 ?m=neg 只自动跑负向对照，加 ?m=pos 只自动跑正式验证（每次新开页面，避免结果互相干扰）。
  5. 先点②负向对照，确认会失败（证明测试环境有效）；再点①正式验证。
  6. 录屏 + 截图保存：页面结论、errMsg 原文、企微版本号、时间。
判读：wx.ready 触发 = 该域名/URL 的签名被客户端接受（危害升级）； wx.error 且 errMsg 含签名或域名相关错误 = 客户端校验拦截（记录原文，危害降级为票据泄露+条件性滥用）。
